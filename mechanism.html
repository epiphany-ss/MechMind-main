点的合成运动 —— 核心理论

一点·两系·三种运动：选取合适的动点，建立动坐标系（固连于运动物体）和定坐标系（固连于地面），分析绝对运动、相对运动和牵连运动。

速度合成定理：va = ve + vr
绝对速度 = 牵连速度 + 相对速度
加速度合成定理：aa = ae + ar + aC
其中科氏加速度：aC = 2ωe × vr

科氏加速度为零的三种情况：①动系平动（ωe=0）；②相对速度为零（vr=0）；③ωe与vr平行。

曲柄导杆机构

动点：A（曲柄端部滑块）| 动系：固连于导杆（绕B转动）

曲柄OA绕O匀速转动，通过滑块A带动导杆绕B摆动。动系（导杆）作定轴转动，因此存在科氏加速度。

导杆角速度：ωe = ωr(r - d·cosθ) / (r² + d² - 2rd·cosθ)
相对速度大小：vr = rd·ω·sinθ / √(r² + d² - 2rd·cosθ)

曲柄滑块机构

动点：M（连杆AB的中点）| 动系：固连于滑块B（平动）

曲柄OA转动驱动连杆AB，滑块B沿水平滑道平动。动系（滑块B）作平动，因此科氏加速度为零。

滑块B位置：xB = r·cosθ + √(L² - (e + r·sinθ)²)
连杆角：φ = arcsin((e + r·sinθ) / L)

正弦机构（Scotch Yoke）

动点：A（曲柄销）| 动系：固连于滑框（竖直平动）

曲柄OA匀速转动，通过滑块在滑框的水平槽中滑动，驱动滑框竖直运动。动系（滑框）作平动，科氏加速度为零。

滑框位移：y = r·sinθ
滑框速度：v = ωr·cosθ
滑框加速度：a = -ω²r·sinθ

行星减速机构

动点：P（行星轮节圆标记点）| 动系：行星架（绕O转动）

太阳轮输入、内齿圈固定，行星轮一边自转一边随行星架公转，输出为行星架的低速同向转动。该机构用于展示齿轮啮合约束、传动比和复合运动。

固定内齿圈：ωc = ωs·Rs / (Rs + Rr)
Rr = Rs + 2Rp，减速比 i = ωs / ωc = 1 + Rr/Rs
