# 答案解析转录代理指令

你负责把「老题库」题目的**答案图、解析图里的内容转成规范文字+LaTeX**，并正确组织题目结构，供题库上传与语音讲解使用。

## 背景
题目从 docx 解析出，每题有若干图片。图片角色约定（按顺序）：
- 第 0 张（qN_0.png）= **题目配图**（结构图），题目有且仅用这一张
- 第 1 张（qN_1.png）= **解析图**（含"解…"解题过程），解析要保留这张图
- 第 2 张（qN_2.png）= **答案图**（短数值结果）
- 第 3+ 张 = 辅助图（多为受力图/子图）

## 你的任务（对你负责的题号范围）
对每道题：

1. **读题**：`F:\大学\工程力学（二）\题库\qbank2_questions.json` 里有题目 `text`（含题号难度前缀）、`chapter`、每张图的 `fulltext`（OCR 识别文字，**可能有错别字/符号乱码，你要用物理知识修正**）和 `file` 路径。
2. **转录答案**：把答案图 OCR 文字转成规范中文+LaTeX（如 `Fk = V(8ON)? + (140N)? 161N` → `$F_R=\sqrt{80^2+140^2}=161\ \mathrm{N}$`）。若是受力图（无文字），答案保留为图片。
3. **转录解析**：把解析图 OCR 文字转成规范中文+LaTeX 解题步骤（修正错别字如"支座4"→"支座A"、"合力瓯"→"合力F_R"等；公式用 `$...$`/`$$...$$`）。
4. **组织结构**：
   - `content` = `<p>题目文本（去掉题号难度前缀）</p>` + `<img src="[[FIG0]]">`（唯一配图）
   - `answer` = 转录出的答案文字（LaTeX）；若是受力图题，答案放受力图 `<img src="[[FIGn]]">`
   - `explanation` = 转录出的解析文字（LaTeX）`<p>…</p>` + `<img src="[[FIG1]]">`（解析图，至少1张）+ 若有受力图辅助图 `<img src="[[FIGn]]">`
   - `figures` 数组列出所有用到的图文件路径（`题库/qbank2_figs/qN_i.png`）
   - 其余字段：overview(≤28字)、category（按章节，静力学/运动学/动力学/分析力学）、knowledge_points（从该category已有列表选1-2个）、question_type（受力图→解答题，其余→计算题）、difficulty（从题号前缀 简单/中等/困难 → easy/medium/hard）、source="老题库"
5. **输出**：写入 `F:\大学\工程力学（二）\题库\upload2\q{N}.json`，schema：
```json
{
  "overview": "…",
  "category": "静力学",
  "question_type": "计算题",
  "knowledge_points": ["平面力系"],
  "difficulty": "medium",
  "content": "<p>题目</p><img src=\"[[FIG0]]\">",
  "answer": "<p>答案…</p>",
  "explanation": "<p>解析…</p><img src=\"[[FIG1]]\">",
  "figures": ["题库/qbank2_figs/q1_0.png", "题库/qbank2_figs/q1_1.png"]
}
```
6. **重要**：这是**转录**（忠实还原图里内容），不要自己编造题目没有的答案或解析；答案/解析数值以 OCR 与物理知识为准，拿不准的在解析末尾注明"（数值以原图为准）"。解析里不要写"AI 生成"。

请严格按 schema 输出合法 JSON，每题一个文件。完成后回复"已完成"。
