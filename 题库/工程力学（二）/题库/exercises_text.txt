第4 章  运动学基础 
一、是非题 
1、描述点的运动常采用矢量法、直角坐标法和自然法。矢量法能同时表示出点的运动
参数的大小和方向。运算简捷，故常应用于理论推证；自然法中把点的运动与其轨迹的
几何性质密切结合起来，使得点的各运动参数的物理意义清楚，所以，已知点的运动轨
迹时，往往采用自然法；采用直角坐标法不需要预先知道点的运动轨迹。因此无论是否
已知点的运动轨迹，都可以应用直角坐标法。

第三篇  动力学 
第7 章  质点动力学基本方程 
 
一、是非题 
1、已知质点的运动方程，就可以确定作用于质点上的力；已知作用于质点上的力，也
可确定质点的运动方程。 
(    ) 
2、在惯性参考系中，不论初始条件如何变化，只要质点不受力的作用，则该质点应保
持静止或匀速直线运动状态。 
(    ) 
3、质点在常力作用下，则只有给定初始条件，才能确定质点运动的轨迹。 
(    ) 
4、一个质点只要有运动，就一定受有力的作用，而且运动的方向就是它受力的方向。 
(    ) 
5、质点运动的速度越大，说明它所受的力也越大。 
(    ) 
6、在同一地点、同一坐标系内，以相同大小的初速度斜抛两质量相同的小球，若不计
空气阻力，则它们落地时速度的大小相同。 
(    ) 
二、选择题 
1、重量为P 的汽车，以匀速v 驶过凹形路面。试问汽车过路面最低点时，对路面的压
力大小           。 
(A)  小于P；            (B)  大于P； 
(C)  等于P；            (D)  已知条件没给够，无法判断。 
2、两个质量相同的质点，沿相同的圆周运动，其中受力较大的质点           。
