# 工程力学题库系统

带后端的本地题库网站，支持**两种运行方式**：服务器模式（数据存 `qdata/` 文件夹）与**纯本地离线模式**（直接双击 HTML 即可使用，数据存浏览器 localStorage）。含三级分类标签、LaTeX 公式、图片、音视频。

## 运行方式

### 方式一：服务器模式（推荐，数据入库 qdata/）

```bash
python server.py
```

浏览器打开 <http://localhost:8090>（默认端口 8090，可在 `server.py` 中改 `PORT`）。
服务器每次写入题目/标签后，会自动把全部数据导出到 `js/data.js`。

### 方式二：纯本地离线模式（双击即用）

直接双击 `index.html` 或 `upload.html` 即可离线使用，无需启动服务器。

- 页面首次打开时，会自动从 `js/data.js`（服务器上次导出的快照）把题目与标签装载到浏览器 localStorage；
- 之后的查看、搜索、筛选、上传、编辑、删除、新增标签、公式与媒体展示全部在本地完成（图片/音频/视频以 data URI 内嵌存储）；
- 顶栏会显示 **💾 离线模式** 徽标；
- 离线期间新增/编辑的题目，下次通过服务器模式打开时会**自动同步**回 `qdata/` 文件夹。

> 提示：为了让 `js/data.js` 保持最新，建议定期用服务器模式打开一次；离线模式浏览器本地存储有上限（约 5MB），超大视频请尽量在服务器模式下上传。

## 页面

| 页面 | 功能 |
| --- | --- |
| `index.html` 题库主页 | 题目查看（卡片列表）、搜索、三级级联筛选、分页、详情弹窗（点击逐级展示 题目→答案→解析）、删除 |
| `upload.html` 上传题目 | 上传 / 编辑题目，拖拽或文件夹选图，音视频上传，三级标签级联选择与新增，LaTeX 公式查看器（实时预览） |

## 数据存储（qdata/）

```
qdata/
├── index.json        题目索引（列表摘要）
├── tags.json         三级分类标签
└── q_001/            每道题一个文件夹
    ├── data.json     题目完整数据（HTML，含 LaTeX / 媒体引用）
    ├── content_img_0.png   题目内图片
    └── explain_media_1.wav 解析内音频/视频
```

`data.json` 字段：

| 字段 | 说明 |
| --- | --- |
| `overview` | 题目概述（卡片展示） |
| `subject` / `category` | 一级学科 / 二级知识大类 |
| `knowledge_points` | 三级知识点，**可多选**，含于所选大类 |
| `question_type` | 题型（判断题 / 选择题 / 填空题 / 解答题 / 证明题，单选） |
| `difficulty` | easy / medium / hard |
| `content` / `answer` / `explanation` | 题目 / 答案 / 解析（HTML，支持 `$…$`、`$$…$$` 公式与 `<img>`/`<audio>`/`<video>`） |
| `media` | 被引用的媒体文件列表 |

## API

| 接口 | 说明 |
| --- | --- |
| `GET /api/list` | 全部题目 |
| `GET /api/question?id=q_001` | 单题详情 |
| `GET /api/tags` | 三级标签 |
| `GET /api/voices` | 讲解音色列表（6 种原神角色风格） |
| `POST /api/upload` | 上传新题 |
| `POST /api/update` | 更新题目 |
| `DELETE /api/delete?id=q_001` | 删除题目 |
| `POST /api/tags` | 新增标签（学科 / 大类 / 知识点） |
| `POST /api/tts` | 试听讲解（按解析内容合成 mp3） |
| `POST /api/narrate` | 生成并存储讲解音频到 qdata/q_XXX/ |
| `DELETE /api/narrate?id=q_001` | 删除讲解音频 |

## 自动讲解系统

按解析文字自动生成讲解音频并存储到 `qdata/q_XXX/`：

- **讲解词逐字对应**：音频严格按解析文字朗读（图片/音视频标签自动跳过）；
- **公式处理（有区分）**：
  - 块级公式 `$$…$$` **不照读**，自动总结成一句话（≤20 字），
    例如动量定理 `mv - mv_0 = \int F d\tau` → “由动量定理，冲量等于动量的改变量”；
  - 行内公式 `$…$` **照着念**（读作字母数字，如 `$m$`→m、`$F=kt$`→F kt、`$\theta$`→theta），不总结；
- **6 种原神角色音色**（用微软神经网络音色 + 音调/语速近似）：

  | 音色 | 角色 | 音色 | 角色 |
  | --- | --- | --- | --- |
  | 御姐音 | 克洛林德 | 少女音 | 宵宫 |
  | 老师音 | 大慈树王 | 少男音 | 重云 |
  | 萝莉音 | 希格雯 | 大叔音 | 法尔加 |

- **用法**：上传页「自动讲解音频」卡片里可试听、可勾选"提交后自动生成"；
  题库详情弹窗底部可播放讲解、重新生成或删除；
- **依赖**：服务器模式需要联网（edge-tts 调用微软语音服务）；离线模式（file://）只能用浏览器自带语音试听，无法生成文件。

### 提示词配置（qdata/tts_prompt.json）

"如何生成讲解"全部集中在这个可编辑配置文件里，修改保存后刷新页面即生效（服务端实时读取）：

```jsonc
{
  "总结要求": "块级公式总结的提示词（也用作 LLM 的系统提示）",
  "行内公式": "行内公式处理方式（默认照着念）",
  "llm": {
    "enabled": false,              // 置 true 并填 api_key 后，块级公式调用大模型总结
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "",
    "model": "deepseek-chat"
  },
  "公式规则": [
    { "匹配": ["\\frac{\\pi^2 EI", "F_{cr}"], "总结": "细长压杆的欧拉临界压力公式" }
  ]
}
```

- `匹配` 为公式中出现的子串，`*` 为通配；匹配忽略反斜杠/花括号/空白（写 `\frac` 或 `\\frac` 均可），命中任一即用对应总结；
- 规则按顺序匹配，越靠前越优先；未命中时回退到"读作字母"或通用话术；
- 配置缺失/损坏时自动回退到内置默认规则；
- LLM 开启时块级公式调用 OpenAI 兼容接口总结，调用失败自动回退到规则。

上传时，前端把题目/答案/解析中的图片、音频、视频以 data URI 内嵌在 HTML 里；后端自动抽取保存为独立文件，并把 `src` 替换为带目录的完整路径（如 `qdata/q_001/content_img_0.png`），保证在站点根目录的页面上能正确加载。更新题目时会自动清理不再引用的媒体文件。

> 兼容旧数据：前端展示时会用 `fixMediaSrc` 自动给"裸文件名"形式的 `src` 补上 `qdata/qid/` 前缀。

## 公式

公式渲染使用自托管的 [KaTeX](js/katex/)（无需联网）。写法：
- 行内公式：`$F = ma$`
- 块级公式：`$$\frac{d}{dt}(m\mathbf{v}) = \mathbf{F}$$`

上传页的「∑ 插入公式」会弹出公式查看器：输入 LaTeX 代码即可实时预览，一键插入行内 / 块级公式。
