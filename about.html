长沙理工大学 · 工程力学系 · 理论力学研究平台

📖 平台简介

长沙理工大学理论力学研究平台是面向工程力学教育的综合性数字化教学平台，由工程力学系师生团队协作开发。平台以"理论结合实际、交互促进理解"为核心理念，整合知识框架梳理、交互式机构演示、分类题库练习、AI智能问答、社区问题探讨、个人学习中心等核心功能，覆盖理论力学课程从静力学基础到分析力学高级专题的全部教学内容。

✨ 核心功能

🧠
知识框架梳理

树状思维导图展示理论力学四大篇章知识体系，由主干到枝干由内向外分散排布，点击节点展开细节，叶子节点直达详细知识框架。

🔬
交互式机构运动演示

曲柄导杆、曲柄滑块、正弦机构三大经典机构的实时运动学动画。支持鼠标拖拽操作与参数调节，速度与加速度矢量动态可视化，科氏加速度实时显示。

📝
分类题库练习

覆盖静力学、运动学、动力学、分析力学四大模块，按难度分级（基础/中等/困难），支持关键词检索、模块筛选与在线作答，题目数据持久化存储。

🤖
AI 智能问答

集成大语言模型的智能力学助教，支持自然语言提问、LaTeX 公式识别与分步推理，可随时解答理论力学学习中的疑难问题。

💬
问题探讨社区

理论学习交流论坛，支持按分类发帖（提问/分享/讨论）、图片上传、评论互动。帖子与评论数据持久化存储，管理员可管理内容。

👤
个人学习中心

学号登录注册系统，区分管理员与普通用户权限。记录个人发帖、评论与做题历史，管理员可管理用户、题目与论坛内容。

🔍
全站搜索引擎

跨模块搜索题库习题、知识概念、论坛帖子与功能页面。支持分词加权匹配与结果高亮显示，快速定位所需资源。

📱
响应式设计

全面适配桌面端、平板和手机端，所有交互功能在移动设备上均可正常使用，随时随地进行理论学习。

🛠 技术架构

前端：HTML5 Canvas 交互绘图 · CSS3 响应式布局 · 原生 JavaScript（无框架依赖）· SVG 矢量图形

后端：Python HTTP Server · RESTful API 接口 · JSON 结构化数据存储 · 文件系统数据库

数据：题库数据 (qdata/) · 论坛数据 (fdata/) · 用户数据 (udata/) · 知识框架 (textbooks/) · 全部本地可运行
