# 理论力学知识框架 · 树状思维总结

> 基于《理论力学研究平台第三代》四大部分教材内容整理

---

## 总体结构

```
理论力学
├── 一、静力学（Statics）
├── 二、运动学（Kinematics）
├── 三、动力学（Dynamics）
└── 四、分析力学（Analytical Mechanics）
```

## 一、静力学

> 核心问题：**物体在力系作用下如何保持平衡？**

```
静力学
├── 1. 绪论与力的基本概念
│   ├── 力的定义与作用效果
│   ├── 力的三要素（大小、方向、作用点）
│   ├── 力的两个重要特性
│   └── 入门实例：为什么推门要推门把手
│
├── 2. 刚体模型、质点模型与变形体
│   ├── 质点模型：忽略尺寸，只关注轨迹
│   ├── 刚体模型：保留尺寸，忽略变形 ← 静力学主要模型
│   ├── 变形体模型：考虑受力后形状改变
│   └── 模型选择原则：研究目标决定模型
│
├── 3. 力的作用线与可传性原理
│   ├── 力的作用线概念
│   ├── 力的可传性原理：沿同一作用线移动，外效应不变
│   ├── 可传性适用范围与限制
│   └── 外力与内力的区分
│
├── 4. 力的表示与分解
│   ├── 力的矢量性质
│   ├── 平面力的正交分解
│   ├── 分量正负号判断
│   └── 力的合成与分解
│
├── 5. 力矩与力臂
│   ├── 力对点之矩：M_O = Fd
│   ├── 力矩方向与符号（右手定则）
│   ├── 求力矩的三种常用方法
│   └── 力臂 = 矩心到力作用线的垂直距离
│
├── 6. 力偶、约束与受力图
│   ├── 力偶的概念与性质
│   ├── 约束与约束反力（光滑面、铰链、固定端等）
│   ├── 受力图绘制规范
│   └── 常见约束类型判断
│
├── 7. 静力学公理
│   ├── 公理一：二力平衡公理
│   ├── 公理二：加减平衡力系公理
│   ├── 公理三：力的平行四边形法则
│   ├── 公理四：作用与反作用公理
│   └── 推论：三力平衡汇交定理
│
├── 8. 力的平移定理
│   ├── 定理内容：F@A ≡ F@O + M₀（附加力偶）
│   ├── 与可传性的关系与区别
│   └── 通向一般力系简化的桥梁
│
├── 9. 平面任意力系
│   ├── 力系分类：汇交力系、平行力系、任意力系
│   ├── 主矢与主矩的概念
│   ├── 力系向一点简化
│   ├── 平衡方程：ΣFx=0, ΣFy=0, ΣM_O=0
│   └── 分布载荷的等效处理
│
├── 10. 空间力系
│   ├── 空间力的分解与方向余弦
│   ├── 空间力矩（向量形式，右手定则）
│   ├── 空间约束反力
│   └── 六个平衡方程（3平动 + 3转动）
│
├── 11. 物体系平衡
│   ├── 整体分析 vs 局部分析
│   ├── 连接处内力与作用反作用
│   ├── 拆分策略：整体求外反力 → 局部求连接力
│   └── 内外力转换原则
│
└── 12. 平面桁架
    ├── 理想桁架三条基本假设（铰接、节点加载、二力杆）
    ├── 节点法：系统求多数杆力
    ├── 截面法：快速求少数指定杆力
    └── 零杆判断：提前简化结构
```

## 二、运动学

> 核心问题：**物体如何运动？（不问"为什么"）**

```
运动学
├── 一、点的运动学（基础）
│   ├── 1.1 矢量法
│   │   ├── 位置矢量 r(t) 描述动点位置
│   │   ├── v = dr/dt，a = dv/dt
│   │   └── 最一般的描述方式
│   │
│   ├── 1.2 直角坐标法
│   │   ├── x(t)、y(t)、z(t) 分量描述
│   │   ├── aₓ = d²x/dt²，aᵧ = d²y/dt²
│   │   └── 最便于计算的方法
│   │
│   ├── 1.3 自然法
│   │   ├── 沿轨迹用弧长 s 描述
│   │   ├── 切向 aₜ 改变速率
│   │   ├── 法向 aₙ = v²/ρ 改变方向
│   │   └── 最贴合轨迹的方法
│   │
│   └── 1.4 切向/法向加速度
│       ├── aₜ 与速度共线，改变速度大小
│       ├── aₙ 指向曲率中心，改变速度方向
│       ├── 总加速度 a = √(aₜ² + aₙ²)
│       └── 匀速圆周运动：aₜ=0，aₙ=v²/R
│
├── 二、刚体的基本运动
│   ├── 2.1 平动
│   │   ├── 刚体内各点速度、加速度相同
│   │   ├── 姿态不变，可用一点代表整体
│   │   └── 包括直线平动和曲线平动
│   │
│   ├── 2.2 定轴转动
│   │   ├── 绕固定轴旋转，轴上各点静止
│   │   ├── 同一刚体角量相同，线量 v=rω
│   │   ├── aₜ = rα，aₙ = rω²
│   │   └── 半径越大，线速度越大
│   │
│   └── 2.3 角速度/角加速度
│       ├── θ → ω = dθ/dt → α = dω/dt
│       ├── 与直线运动 x→v→a 完全类比
│       └── 角量必须用弧度制
│
├── 三、点的合成运动 ★（重点难点）
│   ├── 3.1 动点/动系选择
│   │   ├── 动点：题目要求研究的点
│   │   ├── 静系：地面/机架参考系
│   │   ├── 动系：与运动物体固连
│   │   └── 选系核心：让相对运动变简单
│   │
│   ├── 3.2 速度合成 vₐ = vₑ + vᵣ
│   │   ├── vₐ：绝对速度（静系中）
│   │   ├── vₑ：牵连速度（动系带动）
│   │   ├── vᵣ：相对速度（相对动系）
│   │   └── 矢量三角形合成
│   │
│   ├── 3.3 加速度合成
│   │   ├── aₐ = aₑ + aᵣ + a_c
│   │   ├── 动系转动时多出科氏项
│   │   └── 不能简单对速度公式求导
│   │
│   └── 3.4 科氏加速度
│       ├── a_c = 2ωₑ × vᵣ
│       ├── 出现条件：ωₑ ≠ 0 且 vᵣ ≠ 0
│       └── 平面问题：vᵣ 按 ωₑ 转向转 90°
│
└── 四、刚体平面运动 ★（综合重点）
    ├── 4.1 基点法
    │   ├── 分解为基点平动 + 绕基点转动
    │   ├── v_B = v_A + v_B/A（v_B/A ⊥ AB）
    │   └── 最通用的方法
    │
    ├── 4.2 速度投影法
    │   ├── 刚体上两点速度在连线方向投影相等
    │   ├── 来源于刚体不可变形条件
    │   └── 适合已知方向求大小的题
    │
    ├── 4.3 瞬心法
    │   ├── 瞬时速度中心 I（该点瞬时速度为零）
    │   ├── v = ω · IP，离瞬心越远速度越大
    │   ├── 纯滚动：接触点即瞬心
    │   └── 只能用于速度，不能直接用于加速度
    │
    └── 4.4 加速度合成
        ├── a_B = a_A + a_B/Aᵗ + a_B/Aⁿ
        ├── 切向项 α × r_BA
        ├── 法向项 ω × (ω × r_BA)
        └── 比速度合成多法向项
```

## 三、动力学

> 核心问题：**力如何改变运动？运动背后需要什么力？**

```
动力学
├── 一、质点动力学
│   ├── 1.1 牛顿第二定律
│   │   ├── ΣF = ma（核心桥梁）
│   │   ├── 左边：受力分析
│   │   ├── 右边：运动学加速度
│   │   └── 解题链：受力图 → 坐标轴 → 分量方程 → 加速度
│   │
│   ├── 1.2 运动微分方程
│   │   ├── m r̈ = F(r, v, t)
│   │   ├── 二阶方程，需要两个初始条件
│   │   └── 把力学规律翻译成数学方程
│   │
│   └── 1.3 两类问题
│       ├── 第一类：已知运动 → 求力（求导）
│       └── 第二类：已知力 → 求运动（积分/解方程）
│
├── 二、动量定理（力对时间的累积）
│   ├── 2.1 动量与冲量
│   │   ├── 动量 p = mv（矢量）
│   │   ├── 冲量 I = ∫F dt
│   │   ├── 动量定理：I = Δp
│   │   └── 适合碰撞、打击、短时作用问题
│   │
│   ├── 2.2 质心运动定理
│   │   ├── ΣF_ext = M a_C
│   │   ├── 内力不改变质心运动
│   │   └── 外力为零 → 质心静止或匀速
│   │
│   └── 2.3 变质量系统
│       ├── 质量流入/流出带来动量通量
│       ├── 火箭推进、传送带接收散料
│       └── 不能直接套 F=ma
│
├── 三、动量矩定理（转动动力学）
│   ├── 3.1 转动惯量
│   │   ├── I = ∫r² dm
│   │   ├── 质量远离轴 → I 大 → 更难改变转动
│   │   ├── 平行轴定理：I = I_C + md²
│   │   └── I 与转轴有关，不能脱离轴谈 I
│   │
│   ├── 3.2 定轴转动方程
│   │   ├── ΣM_O = I_O α（转动版 ΣF=ma）
│   │   ├── 力矩与角加速度关系
│   │   └── 过轴的约束反力矩为零
│   │
│   └── 3.3 平面运动微分方程
│       ├── ΣF = m a_C（质心平动）
│       ├── ΣM_C = I_C α（绕质心转动）
│       ├── 两套方程一起用
│       └── 常需运动学约束如 a_C = Rα（纯滚动）
│
└── 四、动能定理（力对位移的累积）
    ├── 4.1 功与动能
    │   ├── 功 W = ∫F·dr（标量）
    │   ├── 动能 T = ½mv²（标量）
    │   └── 力沿位移方向的"有效累积"
    │
    ├── 4.2 动能定理
    │   ├── T₂ - T₁ = W₁₂
    │   ├── 标量方程，适合求速度大小/位移
    │   └── 绕开过程中加速度细节
    │
    ├── 4.3 机械能守恒
    │   ├── T + V = 常数（条件：只有保守力做功）
    │   ├── V 包括重力势能、弹性势能
    │   ├── 守恒不是默认成立，要先验证条件
    │   └── 有摩擦 → 不守恒 → 用动能定理
    │
    └── 4.4 普遍定理综合
        ├── 方法选择能力训练
        ├── 时间短/碰撞 → 动量定理
        ├── 绕点/轴转动 → 动量矩定理
        ├── 速度/位移/高度 → 动能定理
        └── 复杂题分阶段，每阶段选最省定理
```

## 四、分析力学

> 核心问题：**用更普遍的原理处理复杂约束系统**

```
分析力学
├── 一、达朗贝尔原理（从牛顿到分析力学的桥梁）
│   ├── 1.1 惯性力
│   │   ├── F_in = -ma（假想力，非真实作用力）
│   │   ├── 方向与加速度相反
│   │   └── 目的：把动力学问题转化为静力平衡形式
│   │
│   ├── 1.2 动静法
│   │   ├── "先动后静"：求加速度 → 补加惯性力 → 列平衡方程
│   │   ├── ΣF + F_in = 0，ΣM + M_in = 0
│   │   └── 适合求加速运动中的约束反力
│   │
│   └── 1.3 刚体惯性力系简化
│       ├── 分布惯性力 → 惯性主矢 + 惯性主矩
│       ├── F_in = -m a_C
│       ├── M_C^in = -I_C α
│       └── 一个力 + 一个力偶即可等效
│
├── 二、虚位移原理
│   ├── 2.1 约束分类
│   │   ├── 完整约束 vs 非完整约束
│   │   ├── 定常约束 vs 非定常约束
│   │   ├── 双边约束 vs 单边约束
│   │   └── 正确识别 → 正确选广义坐标
│   │
│   ├── 2.2 虚位移 / 虚功
│   │   ├── 虚位移 δr：某瞬时满足约束的无限小可能位移
│   │   ├── 虚功 δW = ΣF_i · δr_i
│   │   ├── 不是实际位移，不含时间演化
│   │   └── 关注"此刻能怎么动"
│   │
│   ├── 2.3 理想约束
│   │   ├── 理想约束：约束反力虚功为零
│   │   ├── 光滑面、不可伸长绳、铰链等
│   │   └── 自动消去理想约束力
│   │
│   └── 2.4 广义力
│       ├── 虚功在广义坐标上的系数
│       └── Q_j = ΣF_i · ∂r_i/∂q_j
│
├── 三、拉格朗日方程
│   ├── 3.1 动力学普遍方程
│   │   ├── Σ(F_i - m_i a_i) · δr_i = 0
│   │   └── 达朗贝尔原理 + 虚位移原理的结合
│   │
│   ├── 3.2 第二类拉格朗日方程
│   │   ├── d/dt(∂T/∂q̇_j) - ∂T/∂q_j = Q_j
│   │   ├── 以广义坐标和能量为核心
│   │   ├── 自动消去理想约束力
│   │   └── 适合多自由度、复杂约束系统
│   │
│   ├── 3.3 能量积分
│   │   ├── 当拉格朗日函数不显含时间时
│   │   └── 广义能量守恒
│   │
│   └── 3.4 循环积分
│       ├── 当拉格朗日函数不显含某广义坐标时
│       └── 对应广义动量守恒
│
├── 四、振动
│   ├── 4.1 单自由度系统自由振动
│   │   ├── m ẍ + kx = 0
│   │   ├── 固有频率 ω_n = √(k/m)
│   │   └── 等幅周期运动
│   │
│   ├── 4.2 单自由度系统受迫振动
│   │   ├── m ẍ + c ẋ + kx = F₀ sin(ωt)
│   │   ├── 共振：激励频率接近固有频率
│   │   └── 阻尼影响振幅衰减
│   │
│   ├── 4.3 两自由度系统振动
│   │   ├── 两个固有频率和主振型
│   │   └── 耦合振动
│   │
│   ├── 4.4 多自由度系统（拓展）
│   │   ├── 矩阵形式：M ẍ + K x = F
│   │   └── 模态分析
│   │
│   └── 4.5 刚体微幅振荡
│       ├── 刚体绕平衡位置小角度摆动
│       └── 等效单自由度问题
│
└── 五、碰撞
    ├── 5.1 碰撞概念
    │   ├── 极短时间内速度突变
    │   ├── 碰撞力远大于普通力
    │   └── 恢复系数 e = 分离速度/接近速度
    │
    ├── 5.2 质点碰撞
    │   ├── 正碰与斜碰
    │   ├── 动量守恒 + 恢复系数
    │   └── 完全弹性(e=1)、完全非弹性(e=0)
    │
    ├── 5.3 刚体碰撞
    │   ├── 需考虑转动效应
    │   ├── 动量矩守恒
    │   └── 碰撞中心概念
    │
    └── 5.4 碰撞能量
        ├── 动能损失计算
        ├── 完全弹性碰撞：动能守恒
        └── 完全非弹性碰撞：动能损失最大
```

## 学习路线建议

1. **静力学** → 掌握受力分析、力系简化、平衡方程（所有后续内容的基础）
2. **运动学** → 学会描述运动，特别是合成运动和平面运动（连接静力与动力的桥梁）
3. **动力学** → 建立力与运动的关系，掌握三大定理（动量、动量矩、动能）
4. **分析力学** → 用更高级的原理处理复杂系统（达朗贝尔 → 虚位移 → 拉格朗日）
